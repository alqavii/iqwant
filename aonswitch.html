Switch Challenge

Each item shows a row of four symbols going in, a row coming out, and an operator in the middle. Work out which 4-digit code turns the top row into the bottom row. This mirrors the Aon (formerly cut-e) "scales switch" format reported in some BP graduate and trading screens.

How a code works. The code says where each output symbol came from. Code 3142 means: output position 1 takes input symbol 3, position 2 takes input 1, position 3 takes input 4, position 4 takes input 2.

Two-step items. After a few correct answers, items chain two operators. One is shown; find the one marked ?.

Scoring. 6 minutes, as many items as you can. Speed matters, but so does accuracy: the real test weighs both, so don't guess wildly.

Keyboard: press 1–4 to pick the 1st–4th code.
